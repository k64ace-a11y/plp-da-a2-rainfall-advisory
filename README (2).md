# Rainfall Advisory

- This project cleans monthly rainfall readings for Nairobi, Nakuru, Kisumu, Mombasa and Machakos, then uses NumPy to analyse annual totals, monthly averages, wettest months, dry months and recommended planting windows.
- To run the analysis, open `rainfall_analysis.ipynb` in Jupyter Notebook or JupyterLab, select the Python kernel, then choose **Kernel → Restart Kernel and Run All Cells**.
- The advisory recommends considering each county's two-month highest-rainfall window when planning planting, while checking current forecasts and local soil conditions because historical monthly rainfall is not a guarantee of future rainfall.
